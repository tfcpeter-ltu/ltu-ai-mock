# 免費自架文法服務

LanguageTool 6.6 + 可攜式 Java 21，無付費推論 API。基礎版提供規則式文法、拼寫、標點建議，不包含供應商雲端 AI 規則，不提供 IELTS Band。Cambridge Write & Improve 另以官方連結提供學生自行使用；沒有自動上傳作文，免費基本版不能當作免費 IELTS Test Zone。

## 本機安裝（Windows）

需要 PowerShell 7 與可用的 Node.js 22／24。從本資料夾執行：

```powershell
./install-windows.ps1
./start-windows.ps1
```

啟動後開啟 http://127.0.0.1:8781/ 即可在這台電腦貼上英文作文測試。頁面不需要輸入金鑰，僅對本機回環及正確 Host 開放；送出檢查必須同源並附專用標頭，以防其他網站或 DNS rebinding 借用本機服務。這不是學生登入入口，不會把測試作文存入網站雲端或本頁歷史。

預設位置為目前電腦的 `%LOCALAPPDATA%\LTU\LanguageTool`，不在 OneDrive。其他電腦依當地環境變數建立自己的環境，不能沿用原電腦的絕對執行檔路徑。

`runtime-versions.json` 保留確切下載網址、版本與 SHA256。Java 校驗碼來自 Adoptium 官方中繼資料；LanguageTool SHA256 是本次官方 HTTPS 下載後的本機鎖定值，沒有宣稱另經供應商簽章驗證。安裝器不會刪除既有檔案或啟用開機啟動。

原始碼、文件及版本清單留在 OneDrive；Java、JAR、壓縮安裝檔、服務記錄與金鑰留在上述本機目錄。`gateway-token.txt` 為閘道驗證金鑰，勿貼在聊天或放入 Git／OneDrive。啟動器使用隱藏程序視窗。

停止服務：

```powershell
./stop-windows.ps1
```

停止前會核對 PID 的程序命令列，避免誤停已被其他程序重用的 PID；不刪除執行檔、學生資料或安裝清單。

## 網站接線

資料流：已登入學生 → GitHub Pages 學習頁 → 認證後的 Convex action → 本站 HTTPS 文法閘道 → 主機本地 LanguageTool。

本機驗證時，Java 僅監聽 127.0.0.1:8081，Node 閘道僅監聽 127.0.0.1:8781。這不代表外地學生能連線。現有 GitHub Pages 不能執行 Java，Convex 也不是 Java 常駐主機，因此正式學生服務仍需要一台已授權、可持續運行的主機與 HTTPS 入口。尚未指定主機前，不自動開防火牆、轉發連接埠、建立公開隧道或註冊付費主機。

主機確認後，讓 HTTPS 反向代理僅轉發 `/v1/check` 至當地主機的 127.0.0.1:8781；不要直接開放 Java 埠。請求由 Convex 提供 Bearer 金鑰，公開前端不會取得金鑰。閘道不會呼叫 LanguageTool 免費公共 API，且拒絕將其上游配置為外部服務。

在 Convex 的伺服器環境變數配置：

- `GRAMMAR_GATEWAY_URL`：已核實的本站 HTTPS `/v1/check` 入口。
- `GRAMMAR_GATEWAY_TOKEN`：與主機私密 token 檔一致，使用安全管道設定，不放命令列或公開前端。
- `GRAMMAR_ENGINE_REVISION`：例如 `LanguageTool-6.6-v1`；更新引擎時調整以使伺服器快取失效。

尚未配置時，前端明確提示主機尚未連線；免費本機寫作檢查、作文保存與學習同步仍可使用，不改用付費備援。

## 用量與個人化

- 每篇上限 12000 字元，英式／美式英文可選；一次最多回傳 60 項建議。
- 閘道最多同時處理兩個請求，忙碌時回覆稍後重試，不無限排隊。
- 每位學生最多約每 15 秒一次新檢查；同一內容與語系的最近結果快取 7 天。
- 每位學生僅保留一筆伺服器快取／限流狀態，以登入身分隔離。原始作文不另外放入快取表；報告隨個人學習狀態保存。
- 文法建議可加入待確認弱點；學生確認後才進正式筆記與原有複習流程。作文變更後舊報告不再套用。
- 規則可能漏判／誤判；未找到錯誤不等於高 Band。雅思切題、論證、組織與句型範圍仍需獨立評閱及教師校準。

免 API 費不代表無限容量或免硬體、電力、網路與維護成本。大量學生的實際吞吐量需在正式主機確定後量測。
